# LaLlajtaExpress SuperApp 🚀

Plataforma integral que combina comercio electrónico, gestión de tareas, chat, análisis de datos, juegos, música, fitness, notas, criptomonedas y más.

## 🎯 Características Principales

### 📱 Apps Integradas (12 componentes)

1. **📋 Gestor de Tareas** - Organiza tus tareas por categorías
2. **🛒 Tienda Online** - Compra productos locales andinos
3. **💬 Chat en Vivo** - Comunícate en tiempo real
4. **📊 Analytics & Reportes** - Analiza datos y ventas
5. **🎮 Tap Clicker** - Juego interactivo con puntos
6. **🎵 Reproductor de Música** - Playlist de música andina
7. **🏋️ Fitness Tracker** - Rastreador de ejercicio
8. **📝 Notas** - Notas con categorías
9. **💳 Crypto Tracker** - Rastreador de criptomonedas
10. **🎨 Portfolio** - Portafolio personal
11. **🌦️ Weather Dashboard** - Clima global en vivo
12. **⏰ World Clock** - Reloj mundial 12 zonas horarias

## 🛠️ Tecnologías

- **React** 18.2
- **Vite** 5.0
- **Tailwind CSS** 3.3
- **Lucide React** (Iconos)
- **localStorage** (Persistencia)

## 📋 Instalación

```bash
# Clonar
git clone https://github.com/henrymancilla980-alt/LaLlajtaExpress.git

# Instalar dependencias
cd LaLlajtaExpress
npm install

# Ejecutar en desarrollo
npm run dev

# Build para producción
npm run build
```
